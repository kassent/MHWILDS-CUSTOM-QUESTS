# 四重奏 · 自制活动任务

[English](README.md) | **简体中文**

本仓库包含 **4 个《怪物猎人：荒野》（Monster Hunter Wilds）自制活动任务**，通过 **REFramework + PermanentEventQuest** 插件加载。

四个任务均在 **龙灯圣域（ST403）** 进行，包含四怪连战、历战王锁刃龙单体、零式欧米茄复刻，以及额外调整怪物机制的高难连战。仓库提供任务配置和 Lua 脚本，不包含 REFramework 或插件本体。

## 任务列表

四个任务的承接条件均为 **HR 100**，最多 **4 人**。

| 任务 ID | 名称 | 星级 | 主要内容 | 时限 | 力尽次数上限 |
|---|---|---|---|---|---|
| 10096 | 终末四重奏 | ★10 | 白炽龙 → 历战黑蚀龙 → 历战王锁刃龙 → 零式欧米茄，四怪连战普通版 | 60 分钟 | 10 |
| 10097 | 一刃当关 | ★10 | 历战王锁刃龙单体，调整解放门槛并支持普通地面生成龙乳结晶 | 50 分钟 | 3 |
| 10098 | 游星浩劫 | ★9 | 零式欧米茄单体，配置场景植物并适配召唤与大招流程 | 50 分钟 | 3 |
| 10099 | 终焉四重奏 | ★10 | 四怪连战高难版，额外调整动作速度、火海、暴走和王锁机制 | 60 分钟 | 10 |

任务名称以任务文件中的简体中文显示名为准；“普通版”表示相对于本仓库高难版，不代表游戏原版难度。

## 玩法与脚本差异

### 10096 · 终末四重奏

- 按顺序挑战四只主目标，击败前一只后进入下一场战斗。
- 为欧米茄配置影蜘蛛、场景植物、对话资源和台词 NPC。
- 调整欧米茄大招中心、蓄力点、爆炸朝向与缩放、召唤落点及绕飞动画，以适配龙灯圣域。
- 不包含 10099 的动作提速、火海寿命、暴走锁定或王锁血量门槛增强。

### 10097 · 一刃当关

- 将王锁的解放资格与自动属性充能加速血量门槛均设为 **100%**。
- 原版判定是严格“小于”：满血时不满足，掉血后获得相应资格；解放仍由原版 AI 调度，不是开局强制切换形态。
- 让原本会生成龙乳结晶的招式在普通地面也能请求创建结晶，不再依赖龙都遗迹的龙乳地形传感器。
- 旧的开局直接写入 `UNLEASH` 方案保留在注释中，当前未启用。

### 10098 · 游星浩劫

- 在龙灯圣域配置零式欧米茄单体战。
- 补齐影蜘蛛召唤、场景植物、对话及台词 NPC，并适配大招位置和绕飞动作。
- 保留本任务原有机制，不加入 10099 的资源参数增强。

### 10099 · 终焉四重奏

在四怪连战基础上增加：

- **动作提速**：白炽龙、黑蚀龙为 1.2 倍，欧米茄为 1.3 倍。
- **火海寿命**：取消芥末炸弹火海的自然寿命倒计时；下一轮施法清场等原版移除逻辑仍保留。
- **暴走锁定**：欧米茄不再因脚伤击破扣减暴走血条而退出暴走，其他原版退出条件仍保留。
- **双影蜘蛛**：配置两只联动召唤用影蜘蛛。
- **王锁增强**：采用与 10097 相同的 100% 血量门槛配置及普通地面龙乳结晶逻辑。

## 安装与使用

1. 安装 REFramework，以及支持本仓库任务脚本 API 的 PermanentEventQuest 插件。脚本使用 `quest.on_load`、`quest.on_unload`、`quest.on_flow_changed` 和 `quest.require_enemies`。
2. 将仓库中的整个 `quests` 文件夹合并到游戏的 `reframework/plugins/PermanentEventQuest/` 下。使用 MO2 时，保持模组内同样的目录层级，并启用模组。
3. 确保四个任务各自的 `.raw.json`、`.ext.json`、`.lua` 文件，以及共享的 `quests/scripts/quest_lib.lua` 都已部署。任务 Lua 由插件托管，不要放入 `autorun`。
4. 在 REFramework 的 **Script Generated UI → Permanent Event Quest** 中点击 **reload**，然后到活动任务柜台选择任务。

更新文件不会修改正在进行的任务实例。修改脚本后，请 reload 并重新进入任务。已有其他任务使用 ID **10096–10099** 时，应先处理 ID 冲突。

## 仓库结构

```text
PermanentEventQuest/
├── README.md
├── README.zh-CN.md
└── quests/
    ├── 10096.raw.json / 10096.ext.json / 10096.lua
    ├── 10097.raw.json / 10097.ext.json / 10097.lua
    ├── 10098.raw.json / 10098.ext.json / 10098.lua
    ├── 10099.raw.json / 10099.ext.json / 10099.lua
    └── scripts/
        └── quest_lib.lua
```

- **`.raw.json`**：任务目标、地图、怪物配置、流程及多语言文本。
- **`.ext.json`**：任务标识、奖励等扩展配置。
- **`.lua`**：任务专属运行时逻辑。
- **`quest_lib.lua`**：共享的敌人注入、对话/NPC 工具，以及按敌人 ID 过滤的 package 加载/卸载事件。

任务脚本的 hook 随任务卸载自动摘除；资源参数修改另行保存原值，通过卸载事件还原，任务结束时由公共库对仍驻留的已订阅包补发清理。联机测试建议所有参与者使用一致的任务文件、共享脚本和插件版本。
